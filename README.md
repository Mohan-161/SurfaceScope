# SurfaceScope

SurfaceScope is a Python-based Attack Surface Discovery and Network Reconnaissance Tool developed for cybersecurity learning and assessment.

## Features

- Host Discovery
- OS Detection
- Port Scanning
- Service Enumeration
- Basic Vulnerability Detection

## Technologies Used

- Python
- Nmap
- python-nmap

## Project Structure

```
SurfaceScope/
│
├── main.py
├── modules/
│   ├── host_discovery.py
│   ├── os_detector.py
│   ├── port_scanner.py
│   ├── service_detector.py
│   └── vuln_detector.py
└── .gitignore
```

## Installation

```bash
pip install python-nmap
sudo apt install nmap
```

## Usage

```bash
python3 main.py
```

Enter the target IP address when prompted.

## Example Output

- Host Discovery
- OS Detection
- Open Ports
- Running Services
- Basic Vulnerability Information
